yb.podcast.feed

Podcast RSS feed generation (iTunes-compatible) via feedgen.

Builds a standards-compliant podcast RSS channel from a channel description and a list of episodes. Chapters travel with the audio (ID3 frames) and/or as a PSC sidecar; a Podcasting-2.0 <podcast:chapters> URL can be supplied per episode.

pubdate is always caller-supplied (never implicitly “now”) to keep feed generation deterministic and reproducible.
