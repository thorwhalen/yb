yb.youtube.captions

Caption (subtitle) tracks on YouTube videos: list, insert, update, upsert.

Lets you attach an SRT/VTT track at upload time and manage tracks on already-published videos — e.g. replace a hand-edited subtitle file, or add a track in a new language. upsert_caption is the convenient default: it updates an existing same-language track if present, else inserts a new one.

Note: YouTube auto-generates ASR tracks of its own (trackKind="asr"); these helpers operate on uploaded "standard" tracks and ignore ASR.
